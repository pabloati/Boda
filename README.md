# Invitación Digital de Boda | Elegant Digital Wedding Invitation

A digital wedding invitation website built with HTML5, CSS3, and vanilla JavaScript. Features a realistic 3D envelope opening animation with wax seal, background romantic audio, live countdown timer, interactive RSVP with instant WhatsApp message generation, event timeline, interactive venue maps, and wedding registry details with 1-click IBAN copy.

## Color Palette
- **Burgundy:** `#6a1a24` / `#4a1018`
- **Sage Green:** `#5e7153` / `#7a8d6e` / `#eef2ec`
- **Warm Champagne / Ivory:** `#fcfaf7` / `#f8f4ee`
- **Gold Accent:** `#c5a059`

## Features
1. **Interactive 3D Envelope Opening**: Realistic envelope with wax seal, "ABRIR" button, unfolding card animation, and auto-playing romantic background music.
2. **Hero & Welcome Section**: Couple names, wedding date, and smooth scroll prompt.
3. **Love Quote & Botanical Monogram**: Serif typography with gold/sage botanical borders.
4. **Parents' Blessing**: Traditional section honoring the parents.
5. **Real-Time Countdown Timer**: Live ticking days, hours, minutes, and seconds.
6. **Locations & Map Integration**: Google Maps links and "Add to Calendar" (.ics & Google Calendar) support.
7. **Itinerary Timeline**: Visual schedule of the day with icons and times.
8. **Interactive RSVP**: Attendance form with WhatsApp auto-formatting, allergy/dietary notes, and bus shuttle reservations.
9. **Dress Code & Kids Policy**: Formal guidelines with recommended color palette swatches.
10. **Gifts & Registry**: Bank transfer details with 1-click IBAN copy button.
11. **Accommodations & Music Suggestions**: Recommended hotels and playlist suggestion box.
12. **Floating Controls**: Background music play/pause toggle and quick RSVP jump button.

## Quick Start (Local Preview)

### Option 1: Direct File Open
Simply double-click `index.html` in your file explorer, or open it in Google Chrome, Firefox, Safari, or Edge.

### Option 2: Local Python Server (Recommended)
Run the following in the project root:
```bash
python3 -m http.server 8000
```
Then open your browser to `http://localhost:8000`.

## Customization
